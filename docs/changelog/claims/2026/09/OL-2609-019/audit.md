### Findings
- **F1** test narrower than claim - C9's "no over-long heading" is not asserted for this page: the only heading-length check, `tests/Feature/HelpContextTest.php:32-35 @f8f6b14`, `continue`s past pages without `context:`, so it never looks at `integration-test-mode.md`. The heading is 34 characters, so it is not too long, but no test checks that. A later claim should drop that part of C9 or cite a test that actually runs on the page.
- **F2** scope - `TestModeToggle.vue:34 @f8f6b14` adds `if (saving.value) return;`, so a click during an in-flight PATCH is now ignored. On the removed page blocks, the `<Label>` click handler had no `disabled` and no guard, so a click on the label mid-request flipped the switch again and sent a second PATCH. No claim records this change in behaviour. It should be recorded in a new claim.
