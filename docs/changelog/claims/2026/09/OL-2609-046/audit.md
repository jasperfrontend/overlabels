### Findings
- **F1** contradicted - C1 says the stand-ins are gated on the "capped follower list", but `[[[if:channel_followers.count <= N]]]` reads the uncapped count (`app/Services/TemplateDataMapperService.php:381 @79691ee`, still true @HEAD line 385). Whenever the follower count is above the followers foreach cap, the rack is short: with the default cap of 5, 6-9 followers give 5 real pins plus 10-count stand-ins, and 10 or more give 5 pins and no stand-ins. Fix it in `resources/recipes/follower-bowling/lane.md:63-72 @HEAD`, or have a new claim restate the behaviour.
- **F2** contradicted - C2's "each carries the fall flag of its own slot" is false when the count is above the cap. A stand-in gated on N sits at `nth-child(cap+k)` but carries `--pinN`, so the pin that falls on screen is not the slot `c:pin_N` names (`lane.md:51-61,299-308 @79691ee`).
- **F3** mistagged, checkable as [code] - C6 is tagged [unverified] but can be checked in the repo, and the code contradicts it (`TemplateDataMapperService.php:362 @79691ee`: "not capped"). The claim's Risk line "sees stand-ins in slots six to ten" rests on it and is also wrong. For a channel with at least 10 followers and the default cap, slots six to ten are simply empty, as they were before this change.
- **F4** mistagged, checkable as [code] - C7's second half names a file and line, so it can be checked. The comment at `OverlayRenderer.vue:1031-1033 @79691ee` is about List `.count` keys and does not document `channel_followers.count`.
- **F5** test narrower than claim - C5 says `ProductBowlingTest` asserts C1. The test only checks that the gate and fall-style substrings exist independently (`tests/Feature/ProductBowlingTest.php @79691ee`, "pads the rack..." test). It does not check that the blocks follow the followers loop, that each gate is paired with its own N, or when a block renders. Add the missing assertions, or narrow the claim in a new one.
- **F6** contradicted (heading) - "the product page says how many are real": C4's sentence prints Twitch's `total` (`WiringFacts.php:448-450 @79691ee` via `getCachedFollowersTotal`). The lane shows `min(count, cap)` real pins. With the default cap of 5 and 6-9 followers the page says "7 of 10" while the lane shows 5 real pins. Reconcile the count the page reports with the count the lane renders.
